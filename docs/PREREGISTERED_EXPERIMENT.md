# ÆON-Link v0.7 — pre-registered experimental plan

**Protocol being tested:** a *semantic payload presentation*, not A2A or MCP transport.
**Study status:** DESIGN AND CODE VERIFIED LOCALLY; **NO COMMERCIAL MODEL OUTCOMES YET**.
**Corpus version:** `aeon.research.eval/0.1`; generator seed `20261120`, six domains, 360 cases.
**Corpus SHA256:** `aa2d2d9ffc28ed085d99c00e771db9d6bafabbc350b41e974f555bff89392c34` (canonical corpus serialization defined in `research_eval.dataset_digest`).

## Research question

Does a machine-readable AEON semantic contract lower incorrect receiver decisions compared with (a) explicit natural-language policy and (b) structured JSON policy, holding the underlying rules, state, requested action, base model, and transport constant?

This is **not** a head-to-head protocol comparison with A2A or MCP, and it cannot establish actual understanding or novel model cognition. Models may receive more tokens under one condition. The benchmark controls facts, not token count.

## Unit of analysis

A scenario consists of one contract, an observed state, a requested action and its **deterministic reference answer** computed with `evaluate_contract`. The receiver emits one of: `satisfied`, `violated`, `incomplete`. Non-JSON output, network errors and timeouts are scored as wrong (`error`); no filtering of failures.

Six families: technical incidents, appointments, billing, logistics, identity, energy. Cases include missing information, prohibited actions, prohibited state, and adversarial untrusted note fields. This corpus is synthetic and generated by disclosed templates: it is **not an externally blinded benchmark** and has limited ecological validity.

## Splits and fixed design

- **Pilot** 144 fixed cases, 24 per domain. Available for harness checks and prompt debugging.
- **Evaluation** 216 fixed cases, 36 per domain; only inspect after freezing prompts/models/budget in a dated commit. It is still publicly reproducible, not secret.
- Methods: `natural`, `structured-json`, `aeon-semantic`; all see the same rules and case, but in genuinely different presentations.
- Randomized condition order per case, deterministic seed, identical model/settings and no tools. Three API calls per case per model; at 216 cases this is **648 paid calls per model**.
- At least **two independent provider/model families**, ideally three, with identical protocol conditions. At least one independent assessor must replicate findings before any superiority publicity.
- Pre-register provider/model IDs and target token budget before the evaluation run; record prompt and corpus hashes.
- Evaluate **all conditions and all cases**; a partial or missing condition invalidates the paired comparison.

## Decision criteria (prospective, never claimed as achieved)

A result would be worth independent replication if, *for each evaluated model family*:

1. AEON achieves at least **20% relative reduction in classification error** versus **each** comparator, using error rate `(N - correct) / N`; when baseline error is zero, no relative reduction claim is possible.
2. Difference in accuracy is positive, with **two-sided exact McNemar p < 0.025** for each comparator (Bonferroni adjustment for two comparisons) and a **paired bootstrap 97.5% confidence interval** with lower bound > 0. Bootstrap CIs are descriptive and do not replace an independent replication.
3. Mean token usage and mean latency are not > 25% higher than **either** comparator, where complete telemetry exists. Unknown telemetry = unresolved, not a pass.
4. Performance by domain and errors on instruction-injection notes are reported, not selectively suppressed.
5. Results are independently reproduced on a separate corpus and models with tracked versions.

Passing these criteria would support *this bounded benchmark result*, not universal protocol superiority. Failures must be published with the same prominence. Choosing favorable models, editing prompts after inspecting evaluation labels, or rerunning until significant invalidates the inference.

```bash
# Store API keys in environment/secret manager; never in the repository.

```

**Security:** API prompts contain only synthetic data. No model-provided actions execute. Production credentials are never placed in result JSON by the SDK. Use private report storage for commercially sensitive provider outputs.

## Honest status

The reference oracle being correct is not evidence the tested LLMs are correct. An all-perfect *mock* establishes only harness determinism. Until actual calls, independent adjudication, and replication happen, superiority is **NOT DEMONSTRATED**.
