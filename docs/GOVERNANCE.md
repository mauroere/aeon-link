# Open governance proposal

Source is MIT-licensed to encourage implementations and criticism. This project is currently a single proof of concept, with **no community governance body or recognized standards status**.

To broaden adoption, propose: public issue templates, specification proposals with examples and threat models, a neutral registry of semantic profiles, independent reference implementations and a recorded public decision process. Changes to core meaning should require a new ontology version and migration tests. Contributors must avoid presenting conformance tests as proof of semantic understanding.

For collaboration, create a dedicated public `aeon-link` repository and publish the files of this package there; no live repository is claimed in this package. CI workflow `.github/workflows/tests.yml` is included for use after publication.
